# LumaRadio
Offline Android radio soundboard with squawk, synthesized Morse patterns, radio static, blaster effects and Alpha–Echo objective tones. Audio is generated locally at runtime, so no external sound files or network service are required. The current release is a tone-based prototype, not recorded spoken announcements.

Run with Godot 4.7.2. Android exports are built by GitHub Actions and uploaded as APK artifacts. Verify on a physical Android device before calling it production-ready.
